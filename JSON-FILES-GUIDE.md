# JSON Files — Plain-English Guide

JSON and web manifests must remain valid JSON. They do not allow `#` or `//` comment lines, so this guide explains the configuration file without changing its format.

- `invoice/manifest.webmanifest` — gives the browser the BNC invoice app's name, icons, and launch/install details.

The JavaScript, CSS, HTML, spreadsheet helpers, and validation scripts have plain-English comments at the top of their files. The workbook and image files are data/assets rather than source code, so they are not modified with code comments.
